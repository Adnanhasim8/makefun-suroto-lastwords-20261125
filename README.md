# Last Words of a Dying AI

Entry for the make.fun competition [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6): one line, at most 140 characters — the last words of an AI being switched off.

The entry is a dying confession: the machine uses its final line to blame the printer. A concrete noun, a hard twist in the last words, and the mystery left unanswered — what did the printer do?

## How to run

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (UTF-8, no trailing newline, no network). Python 3.13 standard library only.
